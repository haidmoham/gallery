# Attribution review — 2026-09-11

The release selection contains 47 works. An independent adversarial review checked illustrator attribution, known cover-design roles, published titles, source links, visible credits, and the code-license boundary.

The attribution gate passed after corrections. This is not reproduction-rights clearance. Reproduction permission has not been established.

## Corrections and limits

- Dialogue and I Want to Touch You and Be Sure credit Yusuke Nakamura for illustration and Yutaka Kimura / Central67 for cover design.
- Publisher and label copyright notices remain distinct from illustrator credit. Unknown visual rights ownership is not invented.
- Twenty-seven older ASIAN KUNG-FU GENERATION covers have dated music-press corroboration scoped to pre-May-2015 releases and its named exception. That secondary source is not represented as a separate written credit for every cover or extended to later releases.
- Empathy was excluded because the checked sources did not establish a sufficiently strong work-specific attribution. Its source record preserves the reason; its image is not shipped.
- The lower-resolution Tatami Time Machine Blues reproduction is also outside the active selection.
- Dates describe publication or release. Titles identify the published cover or commission unless source evidence identifies a standalone illustration title.
- The MIT license covers original gallery code and documentation. It explicitly excludes artwork, imagery, and derived thumbnails.

The evidence and qualifications for each piece are in [the provenance](public/art/art-sources.json). The active display credits are in [the collection](src/works.json). `npm run verify` checks record consistency, known designer credit, source links, image-quality floor, and the licensing boundary. `npm run thumbnails` checks the recorded dimensions against the source files.
